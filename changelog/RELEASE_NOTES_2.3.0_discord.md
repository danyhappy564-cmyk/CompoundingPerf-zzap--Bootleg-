## CompoundingPerf V 2.3.0

**- 레이드 중 게임이 헛되이 쓰던 CPU 2가지 줄이기 (F12 "09.", 기본 켜짐)**

■ 바뀐 것
- 레이드 중 메뉴 배경 영상 멈추기: 레이드 내내 안 보이는 메뉴 영상을 돌리던 것을, 2초마다 확인해서 숨겨져 있으면 일시정지. 게임 코드 수정 없음. (게임 미검증)
- 착지한 에어드랍 물리 끄기: 상자 하나 때문에 레이드 끝까지 맵 전체 물리를 돌리던 것을, 내려앉은 상자만 물리 계산에서 뺌. 올라가기·루팅 그대로, 솔로/Fika 방장만 해당. (게임 미검증)
- 서버 쪽 동작은 2.2.2와 같음. RAM 클리너 웹의 서버 최적화 탭에서도 두 항목 변경 가능

■ 설치
- CompoundingPerf-2.3.0.zip 풀어서 SPT 폴더에 덮어쓰기

■ 주의
- zip의 서버 config.json까지 덮어쓰면 서버 설정이 기본값으로 돌아갑니다. 바꿔 쓰셨다면 그 파일은 빼고 덮어쓰기
- 이상하면 F12 "09." 항목을 끄면 원래대로
