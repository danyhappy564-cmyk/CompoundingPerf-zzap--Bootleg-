[구분선]

■ 바뀐 것

이 모드는 원래 SPT 서버 쪽을 가볍게 하는 모드입니다. 이번에는 게임 안에서 도는 작은 수정 2개가 들어갔습니다(F12 "09. 게임 쪽 CPU 낭비 고치기", 둘 다 기본 켜짐). 서버 쪽 동작은 그대로입니다.

1) 레이드 중 메뉴 배경 영상 멈추기
- 언제: 메인 메뉴 배경이 영상으로 된 배경일 때, 레이드 내내
- 왜: 그 배경은 큰 영상 4개를 계속 돌립니다. 레이드에 들어가면 게임이 배경만 숨기고 영상은 그대로 둬서, 보이지도 않는 영상을 레이드 내내 돌리느라 CPU를 쓰고 있었습니다.
- 이제: 2초마다 확인해서 배경이 숨겨져 있으면 영상을 일시정지하고, 메뉴로 돌아오면 다시 재생합니다. 게임 코드를 고치지 않는 방식이라 화면에 보이는 차이는 없습니다.
- 확인: 아직 게임에서 확인 못 했습니다.

2) 땅에 내려앉은 에어드랍 물리 끄기
- 언제: 에어드랍이 한 번이라도 떨어진 레이드
- 왜: 에어드랍 상자 하나 때문에 레이드가 끝날 때까지 게임이 맵 전체의 물리 계산을 매 프레임 계속 돌렸습니다(맵과 봇 수에 따라 프레임당 1~3ms, 큰 맵일수록 큼).
- 이제: 상자가 완전히 내려앉으면 그 상자만 물리 계산에서 뺍니다. 상자 위에 올라가기와 루팅은 그대로입니다.
- 솔로나 Fika 방장(호스트)에서만 해당됩니다. 레이드 중에 켜면 그 뒤에 떨어지는 상자부터 적용됩니다.
- 확인: 아직 게임에서 확인 못 했습니다.

3) 기타
- RAM 클리너 웹 페이지의 서버 최적화 탭에서도 위 두 항목을 바꿀 수 있습니다.
- 모드 버전과 업데이트 파일 이름이 2.3.0으로 바뀌었습니다.

혹시 이상하면 F12 "09." 항목을 끄면 원래대로 돌아갑니다.

■ 설치

CompoundingPerf-2.3.0.zip 풀어서 SPT 폴더에 덮어쓰기.
zip 안의 서버 설정 파일(config.json)까지 덮어쓰면 서버 설정이 기본값으로 돌아갑니다. 설정을 바꿔 쓰셨다면 그 파일은 빼고 덮어쓰시거나, 덮어쓴 뒤 F12에서 다시 맞춰 주세요.
